# Changelog

## 0.1.2

- Stability updates: fixed excessive memory growth while running in the tray and added rotating local diagnostics for unexpected exits.
- Per-repo version retention: right-click a repo to keep all downloaded versions or keep only the newest. Older tracked downloads are removed only after every matching file in the new release downloads successfully.
- Per-repo extension overrides: choose which file extensions to download for an individual repo.
